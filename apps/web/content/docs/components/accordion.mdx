## Overview

The Accordion component displays collapsible content panels, allowing users to expand and collapse sections to reveal or hide content. Perfect for FAQs, settings panels, or organizing dense information.

## Installation

```bash
bun add @inset/ui
```

## Usage

```tsx
import { Accordion, AccordionItem, AccordionTrigger, AccordionContent } from '@inset/ui/accordion';

export default function Example() {
  return (
    <Accordion>
      <AccordionItem>
        <AccordionTrigger>What is Inset UI?</AccordionTrigger>
        <AccordionContent>
          Inset UI is a component library built with Base UI primitives,
          featuring inner shadows and smooth animations.
        </AccordionContent>
      </AccordionItem>
      <AccordionItem>
        <AccordionTrigger>How do I install it?</AccordionTrigger>
        <AccordionContent>
          Run `bun add @inset/ui` to install the package.
        </AccordionContent>
      </AccordionItem>
    </Accordion>
  );
}
```

## Single vs Multiple

### Single (default)

Only one item can be expanded at a time.

```tsx
<Accordion>
  {/* Only one item open at a time */}
</Accordion>
```

### Multiple

Multiple items can be expanded simultaneously.

```tsx
<Accordion type="multiple">
  {/* Multiple items can be open */}
</Accordion>
```

## Default Open

```tsx
<Accordion defaultValue="item-1">
  <AccordionItem value="item-1">
    <AccordionTrigger>Open by default</AccordionTrigger>
    <AccordionContent>This content is visible initially.</AccordionContent>
  </AccordionItem>
</Accordion>
```

## Props

### Accordion

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `type` | `'single' \| 'multiple'` | `'single'` | Allow one or multiple items open |
| `defaultValue` | `string \| string[]` | - | Initially open item(s) |
| `collapsible` | `boolean` | `true` | Allow all items to be closed |

### AccordionItem

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `value` | `string` | - | Unique identifier for the item |
| `disabled` | `boolean` | `false` | Disable the item |
