## Overview

The Button component is a fundamental interactive element that triggers actions when clicked. It supports multiple visual variants, sizes, and states.

## Installation

<Steps>

<Step>Install the package</Step>

```bash
bun add @inset/ui
```

<Step>Import and use the component</Step>

```tsx
import { Button } from '@inset/ui/button';

export default function Example() {
  return <Button>Click me</Button>;
}
```

</Steps>

## Props

| Prop       | Type                                                 | Default     | Description             |
| ---------- | ---------------------------------------------------- | ----------- | ----------------------- |
| `variant`  | `'default' \| 'destructive' \| 'outline' \| 'ghost'` | `'default'` | Visual style variant    |
| `size`     | `'sm' \| 'md' \| 'lg'`                               | `'md'`      | Button size             |
| `disabled` | `boolean`                                            | `false`     | Disables the button     |
| `asChild`  | `boolean`                                            | `false`     | Render as child element |

## How MDX Components Work

<Callout title="Understanding MDX Components" type="info">
  Every component you see on this page (Callout, Accordion, Steps, etc.) comes from
  `mdx-components.tsx`. This file maps component names to React components, allowing you to use them
  directly in MDX.
</Callout>

The `getMDXComponents()` function in `mdx-components.tsx` returns an object that tells the MDX renderer:

1. **How to style HTML elements** — headings, paragraphs, tables, code blocks
2. **What custom components are available** — Callout, Accordion, Steps, etc.
3. **How to enhance default elements** — add copy buttons to code, icons to filenames

```tsx title="mdx-components.tsx (simplified)"
export function getMDXComponents(overrides = {}) {
  return {
    // Style standard HTML elements
    h1: (props) => <h1 className="text-3xl font-bold" {...props} />,
    h2: (props) => <h2 className="text-xl font-medium" {...props} />,

    // Custom components available in MDX
    Callout,
    Accordion,
    Button,

    // Allow overrides
    ...overrides,
  };
}
```

Then in your docs page:

```tsx title="page.tsx"
<MDX components={getMDXComponents()} />
```
