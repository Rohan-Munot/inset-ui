## Component Library

Inset UI provides a comprehensive set of React components built with Base UI primitives. Each component features our signature inset shadow design, smooth animations, and accessible markup.

## Available Components

### Form Controls

- [Button](/docs/components/button) - Clickable button with multiple variants
- [Input](/docs/components/input) - Text input field with label support
- [Checkbox](/docs/components/checkbox) - Single checkbox control
- [Checkbox Group](/docs/components/checkbox-group) - Group of related checkboxes

### Data Display

- [Avatar](/docs/components/avatar) - User avatar with fallback support
- [Accordion](/docs/components/accordion) - Collapsible content sections

### Navigation

- [Autocomplete](/docs/components/autocomplete) - Text input with suggestions
- [Combobox](/docs/components/combobox) - Searchable dropdown selection

### Overlay

- [Alert Dialog](/docs/components/alert-dialog) - Modal dialog for important actions

### Utilities

- [Collapsible](/docs/components/collapsible) - Expand/collapse content areas
- [Scroll Area](/docs/components/scroll-area) - Custom scrollbar container
- [Label](/docs/components/label) - Accessible form labels
