# Getting Started

Get up and running with Inset UI in your React project.

## Installation

```bash
bun add @inset/ui
```

## Usage

Import components from the package:

```tsx
import { Button } from '@inset/ui/button';

export function MyComponent() {
  return <Button>Click me</Button>;
}
```

## Styling

Inset UI uses Tailwind CSS v4. Make sure to import the global styles in your root layout:

```tsx
import '@inset/ui/global.css';
```
