## Introduction

Welcome to **Inset UI** documentation! This guide will help you get started with our component library.

## Installation

```bash
bun add @inset/ui
```

## Quick Start

Import and use components in your React application:

```tsx
import { Button } from '@inset/ui';

export default function App() {
  return (
    <Button>Click me</Button>
  );
}
```

## Features

- 🎨 **Beautiful Design** - Modern, premium UI components
- 🌙 **Dark Mode** - Built-in theme support
- ⚡ **Performance** - Optimized for speed
- 📱 **Responsive** - Works on all screen sizes
