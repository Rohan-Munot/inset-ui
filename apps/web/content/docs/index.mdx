# Welcome to Inset UI

Inset UI is a personal learning project for building reusable React components using [Base UI](https://base-ui.com/) as unstyled primitives.

## Design Philosophy

The name "Inset" reflects the design philosophy: components feature **inner shadows**, **smooth animations**, and a refined, **tactile aesthetic**.

## Features

- Built on Base UI primitives for accessibility
- Compound component architecture
- Tailwind CSS v4 styling
- Dark mode support out of the box
- Smooth 200ms transitions

Explore the components in the sidebar to see what's available.
